# Security Policy

tsx2rs renders untrusted data into HTML and RSC payloads, so escaping and input validation bugs are security bugs.

## Reporting a vulnerability

Please **do not open a public issue.** Report privately through GitHub's "Report a vulnerability" (Security → Advisories) on this repository. Include a minimal reproduction if possible.

We aim to acknowledge reports within 3 working days and to agree on a disclosure timeline with the reporter.

## Supported versions

Until 1.0, only the latest release receives fixes.
